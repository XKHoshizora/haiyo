# 手机验证清单（2026-11-25 上线的这一批）

验收站点 test.haiyo.org，TestFlight 里的 Haiyo。先把应用彻底关掉再打开一次，让它加载新版网页。

每一项回“是 / 否”就行。“否”的时候请录屏或截图，并说一句刚才做了什么。

说明：表情面板、长按消息弹出的菜单、输入 @ 时的成员列表不算弹窗，在它们后面拖动时消息列表可以滚，这是正常的。

## 一、弹窗后面的页面不动（最重要）

1. 打开“设置 › 记忆宫殿”，把页面往下滑一点，点“用哪个模型整理记忆”。面板打开时**不应该**自动弹出键盘；每一行模型都完整，“管理供应商”在最下面。
2. 手指按在**模型列表**上上下拖：后面的页面动不动？模型多的时候列表自己能不能滚？
3. 手指按在**搜索框那一行**上下拖：后面的页面动不动？
4. 手指按在**“管理供应商”那一行**上下拖：后面的页面动不动？
5. 点一下搜索框让**键盘弹出**，把第 2 到 4 步再做一遍。请分别告诉我“键盘收起时”和“键盘弹出时”的结果，这两种情况的原因不同。
6. 关掉面板：后面的页面是否还在打开前的位置；面板打开和关闭的瞬间，后面的页面有没有**闪一下**。
7. 任选一个确认对话框（例如删除、退出群聊）：按在对话框上、按在变暗的地方上下拖，后面的页面不动。
8. 聊天里点开一张图片：单指在图片外的黑色区域上下拖，后面的聊天记录不动。

## 二、弹窗里面的操作

9. 模型很多的面板：**拇指单手、斜着起手**滑列表，连续 10 次，每次列表都跟手吗？
10. 模型很多时：列表底部有一条淡淡的阴影表示“下面还有”，滑到最后一行阴影消失。
11. 换头像的对话框：**缩放滑块**能拖动，双指缩放能用。
12. 聊天里点开图片：双指缩放、放大后单指拖动，和以前一样。
13. 任意面板或对话框打开时，从屏幕**左边缘向右滑**：只关掉面板或对话框，页面不后退。

## 三、登录页的邮箱输入框

14. 登录页点“邮箱”：能不能切到你的第三方键盘。
15. “忘记密码”页点“邮箱”：能不能切到第三方键盘。
16. 登录页：系统是否仍然提示填入已保存的账号密码。
17. 如果第 14 步不行而第 15 步可以，请直接告诉我，这是预料中的一种结果（登录页的邮箱框后面紧跟着密码框，系统可能仍把它当成账号框）。

## 四、思考档位

18. “模型供应商 › 编辑”，找一个支持思考的模型，点“高级”，在“思考档位”里选“全部档位”，保存。
19. 重新进入编辑页：两个选项**还在**；选回按模型报告的档位，保存，再进来确认已经改回。

## 五、“真人”标签

20. 和好友的私聊：标题下面**没有**“真人私聊”，名字和头像对齐，没有空出一行。
21. 有 Agent 的群：标题下面是“小人图标 数字 ｜ 机器人图标 数字”，一行，不换行。一眼能看懂吗？
22. 没有 Agent 的群：只有“小人图标 数字”。
23. “群资料 › 群成员”和“会话资料 › 发言成员”：人的名字后面没有“真人”；Agent 仍有“Agent”标签和“主人：某某”。
24. “Agent”页点开一个在群里的 Agent，看它参与的会话：每个群的第二行是图标加数字，不是空的。
25. 三句改过的话读着顺不顺：
    - 让 Agent 停下被拒绝时：“只有群里的人可以让 Agent 停下。”
    - 群里只剩你和 Agent、你要退出时：“群里除了 Agent 只剩你了，退出后这个群会关闭。”
    - 创建 Agent 页那段说明：“在没有人发言的这段时间里，它被其他 Agent 叫动所花的点数到了这个数就不再接话；有人发言后重新计算。有人 @ 它时不受限制。”

## 六、图片按钮发视频

26. 聊天里点图片按钮，选一段短视频发送：能发出、能播放。
27. 同时选几张照片和一段视频：各自成为一条消息，顺序正确。
