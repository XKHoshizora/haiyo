# 日本《电气通信事业法》：Haiyo 要不要向总务省申报

> **这是调研整理，不是法律意见。** 2026-11-23 读取；[n] 见文末出处。

## 1. 一句话结论

**现在（免费、邀请制、小范围试用、无收入）大概率还不用申报；开始收费（积分）或靠广告赚钱之前，必须做"届出"（向总务省事前申报，不审批、免费）。** 把握：收费后要申报——高；现在不用——中。关键是算不算"经营"（営む）：想从服务本身获利而反复提供才算，不图利或"试验性"提供不算 [1][2]。住国外也适用，另需日本国内代理人 [4]。

## 2. 为什么可能适用

法律管"替别人传话"（他人の通信を媒介）：发件人指定收件人，服务器原样送达；用云、服务器在境外都算 [1][2]。官方明列聊天 App、封闭群聊、产品内私信要申报，公开论坛不算 [1][2]。Haiyo 的一对一和群聊属前者；Agent 发的消息即使不算传话 [20]，人与人的消息已足够触发。不自建线路，所以是简单的"届出"，不是要审查的"登録" [1]。用日语提供或日元收费即算面向日本 [4]。

## 3. 如果适用要做什么

| 项目 | 内容 |
|---|---|
| 交什么 | 申报书（様式第8）、网络结构图（様式第3）、服务说明（様式第4）、住民票 [5]；住国外另交代理人的住民票或登记证明、授权书（様式第2の2）、译文 [6] |
| 交给谁 | 本人住址所属的地方通信局（総合通信局；关东 03-6238-1675）；住国外按代理人住址 [3][6]。按"信书"邮寄（不能用宅配）或 e-Gov 在线 [5][7] |
| 何时 | 开始经营之前 [7]，实操上即收费功能上线前 |
| 费用 | 手续费 0 [7]；国内代理人（可请日本律师 [11]）费用未查到 |
| 多久 | 不审批，提交即完成；之后寄回"通知书"，天数未查到 [7][12] |
| 之后 | 资料变更、停服、重大事故要报；遵守通信保密 [12] |

## 4. 不做的后果

不申报就经营：最高 6 个月监禁或 50 万日元罚金（第185条）[8]；网上"1 年/100 万"的说法 [15] 与条文不符。境外运营者违法还可被公布姓名 [4]。

## 5. 对产品的另外两点影响

**通信保密（Agent 读消息）。** 服务器让 Agent 读、存消息并发给外部 AI 公司，即使全由机器处理也算"获知"内容 [9]，存档同样受保护 [18]。须有每位通信当事人逐项、具体、明确的同意：单独勾选、不默认勾上，不能只靠条款或"继续使用即同意" [9][10]。他人代为同意无效 [10]，所以群里别人的 Agent 读我的消息，需我本人同意（推断）。示例："有 Agent 的对话里，你的消息会被服务器读取并发给 AI 服务商（名称、国家）以生成回复，保存 N 天，可随时关闭。☐同意"。违反最高 2 年/100 万日元 [8]。

**外部送信。** 网页和 App 里让用户设备把信息发给第三方的代码（统计、错误监控 SDK 等），都要公开发什么、发给谁、何用，不论规模 [13][14]；"1000 万/500 万人"门槛属另一套大平台规则 [16]。服务器调 AI 接口归通信保密管。

## 6. 我没能确认的

- 已计划收费的免费试用算不算经营：官方说"想获利就算"，又说"试验性不算" [1][2]。
- 通知书多久到、代理人费用、个人姓名是否公开。
- Agent 读群聊消息的同意怎样取才够，官方没有针对 AI 的说明。
- 个人信息保护法（数据出境）不在本文范围。

## 7. 建议

先打电话问住址所属総合通信局的电気通信事業課（官方指定的咨询窗口 [2][7]）；手册里的邮箱，官网写明原则上不逐一回复 [3]。要书面答复可走"法令适用事前确认"（30 天内答复并公开）[17]，或找律师。可直接发的三个问题：

1. 個人で、招待制・無料の試験運用として、利用者間の1対1・グループのメッセージを媒介するサービスを提供しています。将来は有料ポイントを導入予定です。現時点で届出は必要ですか。必要になるのはどの時点ですか。
   （我个人以邀请制免费试运行提供一对一和群聊，将来计划收费积分。现在要申报吗？从何时起要？）
2. 運営者が海外在住の場合、国内代理人はどのような者でもよいですか。届出先はどこになりますか。
   （运营者住国外时，国内代理人可以是什么人？交到哪里？）
3. 利用者のAIエージェントが会話中のメッセージをサーバー上で自動解析し、外部のAI事業者にも送信して返信します。通信の秘密との関係で、会話の参加者全員から、どのような形の同意を得れば足りますか。
   （用户的 AI Agent 在服务器上自动解析会话消息并发给外部 AI 公司来回复。按通信保密，要从每个参与者取得什么形式的同意才够？）
