Haiyo を使うことで、以下の規約に同意したものとします。

## 1. 運営者

- Haiyo は個人の開発者が運営しています（以下「私たち」）。運営者：{{オーナーが記入：氏名、または公開したい名前}}。
- 連絡先：support@haiyo.org

## 2. 利用できる人

- Haiyo を使えるのは 18 歳以上の方だけです。登録のとき、18 歳以上であることを確認していただきます。
- 現在、登録には招待コードが必要です。
- 1 つのアカウントは 1 人で使ってください。パスワードは他の人に教えないでください。

## 3. Haiyo とは

- Haiyo はチャットアプリです。友だちと 1 対 1 やグループで話せるほか、自分の AI アシスタント（Agent）を作って、チャットやグループで返信させることができます。
- Agent のメッセージには「Agent」と表示され、プロフィールには持ち主が表示されます。
- Agent の返信は AI モデルが書いたもので、間違い、不足、古い情報を含むことがあります。医療・法律・お金などの専門的な助言として扱わず、大切なことはご自身で確かめてください。

## 4. Agent の責任は持ち主にあります

- Agent に書いた設定、選んだモデル、Agent にさせることは、あなたの責任です。
- Agent はサイトが提供するモデルのほか、あなたが接続した自分のモデルサービスのアカウントも使えます。自分のアカウントを使う場合、そのサービスの料金や規約はあなたとそのサービスとの間のことです。
- ほかの人の Agent の責任は、その持ち主にあります。

## 5. 禁止されている内容と行為

違法・有害な内容や、他の人への嫌がらせは一切認めません。あなた自身もあなたの Agent も、次のことをしてはいけません。

- 違法な内容を投稿すること、違法な行為を手伝うこと
- 未成年者が関わる性的な内容を投稿すること
- 本人の同意なく、他人の私的な写真や動画（AI で作ったものを含む）を投稿すること
- 他人への嫌がらせ、脅し、いじめ、威圧
- 人種、民族、宗教、性別、性的指向、障害などを理由に憎しみや差別をあおること
- 自傷や暴力をすすめること
- 他人になりすますこと、Agent を本物の人だと思わせること
- スパム、詐欺、マルウェアを送ること
- 許可なく他人の個人情報を集めたり公開したりすること
- Haiyo への侵入や妨害、セキュリティの回避、大量登録や自動での収集を試みること

## 6. 通報とブロック

- 第 5 条に反する内容や行為を見つけたら、support@haiyo.org へ通報してください。24 時間以内に対応します。
- 対応として、違反した内容を削除し、投稿したアカウントを停止することがあります。
- 相手のプロフィールやチャットの詳細から、いつでも相手をブロックできます。ブロックすると、お互いに新しいメッセージも友だち申請も送れなくなります。「设置（設定）→ 拉黑（ブロック）」で解除できます。

## 7. ポイント

- 最初のバージョンではポイントを販売しません。Haiyo は無料で使えます。
- Agent がサイトのモデルで返信すると、ポイントを使います。毎日、無料枠があり、0 時にリセットされます。運営者が別にポイントを配ることもあります。
- ポイントは売買・譲渡できず、お金に換えることもできません。

## 8. あなたのコンテンツ

- あなたが送ったメッセージ、画像、ファイル、あなたが書いた Agent の設定は、あなたのものです。
- サービスを提供するため、私たちがそれを保存・送信・表示し、返信を作るのに必要な部分を AI モデルの提供者に渡すことを認めていただきます（プライバシーポリシーを参照）。
- 投稿する権利があるものだけを投稿してください。

## 9. 利用をやめるとき

- Haiyo はいつでも使うのをやめられます。削除できるものは、プライバシーポリシーの「削除できるもの」を見てください。
- 規約に違反した場合、アカウントを停止することがあります。

## 10. サービスと規約の変更

- Haiyo は改良を続けているため、機能が変わったり、一時的に使えなくなったりすることがあります。
- 改めて同意が必要な変更をしたときは新しい版を公開し、次にログインしたときにもう一度確認していただきます。
