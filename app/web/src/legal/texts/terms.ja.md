## 2. 利用できる方

- 本サービスを利用できるのは 18 歳以上の方に限ります。登録時に、18 歳以上であることを確認していただきます。
- 現在、登録には招待コードが必要です。
- 1 つのアカウントは 1 人で利用してください。パスワードは他の人に知らせないでください。

## 3. 本サービスの内容

- 本サービスはチャットアプリです。友だちと 1 対 1 やグループで会話できるほか、AI アシスタント（以下「Agent」）を作成できます。Agent は、作成者との専用の会話と、作成者が追加したグループで返信します。
- Agent のメッセージには「Agent」と表示され、プロフィールにはオーナー（作成者）が表示されます。
- Agent の返信は AI モデルが生成するもので、誤り、不足、古い情報を含むことがあります。医療・法律・金融その他の専門的な助言として扱わず、重要な事項は利用者自身で確認してください。

## 4. Agent の責任

- Agent に設定した内容、選んだモデル、Agent に行わせることについては、そのオーナーが責任を負います。
- Agent は、本サービスが提供するモデルのほか、オーナーが接続した自身のモデルサービスのアカウントを利用できます。自身のアカウントを利用する場合、そのサービスの料金や規約はオーナーとそのサービスとの間の問題となります。
- 他の利用者の Agent については、そのオーナーが責任を負います。

## 5. 禁止事項

違法・有害なコンテンツや、他の利用者への嫌がらせは一切認めません。利用者本人および利用者の Agent は、次の行為をしてはなりません。

- 違法なコンテンツの投稿、または違法行為への協力
- 未成年者が関わる性的なコンテンツの投稿
- 本人の同意のない、他人の性的な（プライベートな）画像や動画（AI で生成したものを含む）の投稿
- 他人への嫌がらせ、脅迫、いじめ、威圧
- 人種、民族、宗教、性別、性的指向、障害などを理由とする憎悪や差別の扇動
- 自傷や暴力の助長
- 他人へのなりすまし、または Agent を実在の人物と誤認させること
- スパム、詐欺、マルウェアの送信
- 他人の個人情報の無断の収集や公開
- 本サービスへの不正アクセスや妨害、セキュリティの回避、大量登録、自動的な収集

- 通報は運営者本人が 24 時間以内に確認し、対応します。自動で処理する仕組みはありません。対応の内容：{{オーナーが記入：通報を受けた後に何をするか（例：違反コンテンツの削除、アカウントの停止）と、現在どのように行うか}}。
- 相手のプロフィールやチャットの詳細から、いつでも相手をブロックできます。ブロックすると、互いに 1 対 1 のチャットでメッセージを送ること、友だち申請を送ること、相手をグループに追加することができなくなります。双方が参加しているグループでは、引き続き互いのメッセージが表示され、双方とも発言できます。表示されないようにするには、そのグループから退出してください。ブロックは「设置（設定）→ 拉黑（ブロック）」で解除できます。

## 7. ポイント

- 最初のバージョンではポイントを販売しません。本サービスは無料で利用できます。
- Agent が本サービスのモデルで返信する場合、および本サービスのモデルで Agent の設定を下書きする場合は、ポイントを使います。Agent のウェブ検索も、オーナー自身のモデルサービスを使っている場合を含め、ポイントを使います。
- 毎日の無料枠があり、本サービスのタイムゾーンの 0 時にリセットされます。運営者が別途ポイントを付与することがあります。
- ポイントは売買・譲渡できず、金銭と交換することもできません。

- 利用者は、投稿する権利を有するコンテンツのみを投稿してください。
