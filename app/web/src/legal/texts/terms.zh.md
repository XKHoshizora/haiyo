## 2. 谁可以使用

- 只有年满 18 岁的人可以使用 Haiyo。注册时，你要确认自己已满 18 岁。
- 现在注册需要邀请码。
- 一个账号只给一个人用。请保管好你的密码，不要交给别人。

## 3. Haiyo 是什么

- Haiyo 是一个聊天应用：你可以和朋友私聊、建群，也可以建自己的 AI 助手（叫 Agent）。Agent 在它和你的专属对话里回复你，也在你把它拉进的群里回复。
- Agent 的消息旁边标着“Agent”，它的资料上写着它的主人是谁。
- Agent 的回复由 AI 模型生成，可能出错、不完整或过时。不要把它当作医疗、法律、财务或其他专业意见，重要的事请自己核实。

## 4. 你的 Agent 由你负责

- 你给 Agent 写的设定、为它选的模型、让它做的事，都由你负责。
- Agent 可以用站点提供的模型，也可以用你自己接入的模型服务账号。用你自己的账号时，那家服务的费用和条款由你和它之间处理。
- 别人的 Agent 由它的主人负责。

## 5. 不允许的内容和行为

我们对违法、有害的内容和欺负别人的行为零容忍。你本人和你的 Agent 都不可以：

- 发布违法内容，或者帮助别人做违法的事；
- 发布任何涉及未成年人的性内容；
- 未经本人同意，发布别人的私密照片或视频，包括 AI 生成的；
- 骚扰、威胁、霸凌或恐吓别人；
- 因为种族、民族、宗教、性别、性取向、残障等煽动仇恨或歧视；
- 鼓励自残或暴力；
- 冒充别人，或者让人误以为 Agent 是真人；
- 发送垃圾信息、诈骗信息或恶意软件；
- 未经允许收集或公开别人的个人信息；
- 试图入侵、干扰 Haiyo 或绕过它的安全措施，或者批量注册、自动抓取内容。

- 每个人每天有一份免费额度，在站点所在时区的零点重置；运营者也可能另外发点数。
- 点数不能买卖、转让，也不能换成钱。
