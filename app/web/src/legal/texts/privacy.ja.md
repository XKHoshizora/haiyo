## 保存するもの

- アカウント：メールアドレス、表示名、アカウント名、アイコン、パスワード。パスワードはハッシュだけを保存し、私たちには元のパスワードは見えません。
- あなたの確認：どの版の利用規約とプライバシーポリシーにいつ同意したか、18 歳以上であることをいつ確認したか。生年月日は尋ねず、保存もしません。
- あなたが送ったもの：チャットやグループのメッセージ、送った画像とファイル。
- あなたの Agent：名前、アイコン、あなたが書いた設定とその他の設定。Agent の記憶メモ（あなたについてのメモや、グループで聞いた他の人の発言を含む。記憶がオンのときだけ）。
- つながり：友だち、友だち申請、ブロック、参加しているグループ。
- 利用量：AI モデルを呼ぶごとに、どのモデルを使い、何トークン、何ポイント使ったか。ポイントの残高とその変化。
- あなたが接続したモデルサービス：サービスのアドレスと API キー。キーは暗号化して保存し、そのサービスを呼ぶときだけ復号します。
- サーバーのログ：リクエストごとのメソッド、パス、ホスト、あなたの IP アドレス。アドレスのクエリ部分（検索語やリンク内のトークンなど）は消し、Cookie はログに残しません。メッセージやメモの内容もログに残しません。
- あなたのブラウザ：ログイン用の Cookie（スクリプトからは読めません）。返信の下にポイントを表示するかどうかなど、ブラウザの中だけで使う少しの記録もあり、私たちには送りません。

広告や分析のサービスは使っていません。

## 使いみち

- メッセージを保存して届け、どの端末でも同じ内容が見られるようにするため。
- Agent が返信し、物事を覚え、記憶を整理するため。Agent の持ち主が「主动参与群聊」（自分からグループの会話に参加する）をオンにしているときは、グループで話すかどうかを判断するため。
- 利用量とポイントを計算し、乱用を防ぐため（リクエストの回数を制限するなど）。
- アカウントのメール：メールアドレスの確認、パスワードの再設定、誰かがあなたのアドレスで登録しようとしたときのお知らせ。
- お問い合わせへの返信と通報への対応。

あなたの情報を売ったり、広告に使ったり、アプリをまたいで追跡したりはしません。

## 渡す相手

Agent の返信は AI モデルが書くため、内容を AI モデルの提供者に送る必要があります。

- サイトのモデル：運営者がこれらの提供者のアカウントを持っています。現在使っているのは：{{オーナーが記入：サイトのモデルの提供者名}}。
- Agent の持ち主が接続したモデルサービス：Agent の持ち主が自分のアカウントを接続している場合、その Agent のリクエストはそこへ送られます。そのサービスは持ち主が選んだもので、データの扱いはそのサービスのポリシーに従います。

モデルに送る内容には、Agent の設定とメモ、会話の最近のメッセージ（グループでは他のメンバーの発言も含みますが、その Agent がグループに入ってからのものだけ）、メンバーの名前、モデルが読める画像とファイルが含まれます。

次の提供者も一部の情報を受け取ります。

- ウェブ検索：Agent のウェブ検索がオンのとき、Agent が考えた検索語を検索サービスに送り（サイトは Exa か DeepSeek を使えます。運営者が設定します）、見つかった内容をモデルに渡します。
- メール：サイトがメールを送るときは Resend を使います。Resend はあなたのアドレスとメールの内容を受け取ります。

## グループの他の人に見えるもの

- グループのメンバーには、あなたがそのグループで送ったメッセージやファイルが見えます。
- グループに他の人の Agent がいる場合、あなたのグループでの発言は、その Agent のモデルにも返信を作るために渡され、Agent の記憶に残ることもあります。

## 保存期間

- メッセージ、画像、ファイル：会話の中に保存されます。現在、自動では削除されません。
- アップロードしたまま送らなかったファイル：1 時間後に削除します。
- 記憶の変更記録：30 日後に削除します。
- ささやき（Agent が持ち主だけに見せるメモ）：誰も対応しないものは 7 日で期限切れになり、対応済みや期限切れのものは表示されてから 30 日後に削除します。
- ログイン：7 日間有効です。メールアドレス確認のリンクは 24 時間、パスワード再設定のリンクは 1 時間有効です。
- アカウント、Agent、利用量、メールの記録：現在は保存したままです。
- サーバーのログ：{{オーナーが記入：ホスティング事業者がログを保存する期間}}。

## 削除できるもの

今できること：

- 自分の Agent を削除する（グループでの Agent の発言は残ります）
- Agent の記憶メモを削除する
- 接続したモデルサービスとそのキーを削除する
- アイコンを変える
- グループを抜ける、友だちを削除する、相手をブロックする

送ったメッセージは今のところ削除できません。

## AI にあなたの発言を読ませないようにするには

今のところ専用の切り替えはありません。Agent と話すのをやめ、Agent がいるグループを抜けることはできます。

## 未成年の方

Haiyo は 18 歳以上の方だけが使えます。18 歳未満の方が使っていることをご存じの場合は、お知らせください。{{オーナーが確認：その後の対応。}}

## セキュリティ

- サイトは HTTPS を使っています。
- パスワードはハッシュだけを保存し、モデルサービスのキーは暗号化して保存します。
- ログイン用の Cookie はスクリプトから読めません。

## ポリシーの変更

改めて同意が必要な変更をしたときは新しい版を公開し、次にログインしたときにもう一度確認していただきます。
