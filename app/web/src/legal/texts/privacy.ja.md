## 保存する情報

- アカウント：メールアドレス、表示名、アカウント名、アイコン、パスワード。パスワードはハッシュのみを保存し、運営者が元のパスワードを見ることはできません。
- 使わなくなったアカウント名：アカウント名を変更した後も、以前の名前は本人用に保持され、他の利用者は使えません。
- 招待：登録に使った招待コード。
- ログインごとの記録：開始日時、有効期限、ブラウザや端末の説明（ブラウザが送る User-Agent。例：ブラウザの名前とバージョン。Haiyo の iOS アプリではアプリのバージョンを含みます）。ログインの記録に IP アドレスは保存しません。
- 同意の記録：どの版の利用規約とプライバシーポリシーにいつ同意したか、18 歳以上であることをいつ確認したか。生年月日は尋ねず、保存もしません。
- 送信した内容：チャットやグループのメッセージ、送信した画像とファイル、各会話をどこまで読んだか。
- 利用者の Agent：名前、アイコン、作成した設定とその他の設定、各人の呼び方。Agent の返信（モデルが思考の過程を書き出した場合はそれも返信とともに保存し、グループではオーナーにのみ表示します）。Agent が提案した設定の変更。返信ごとの実行記録（状態、日時、失敗の理由）。
- Agent の記憶（記憶がオンの間のみ）：オーナーについてのメモ、Agent 自身が学んだこと、Agent がグループで聞いた他の人の発言（発言者の名前とグループ名を含みます）。
- 会話の要約：会話が長くなると、Agent はモデルを使って古い部分を要約し、会話と Agent ごとに 1 つ保存します。
- ささやき：Agent がオーナーにだけ見せるメモ。記憶の変更記録。
- つながり：友だち、友だち申請、ブロック、参加しているグループ。
- 利用量：AI モデルを呼び出すごとに、使ったモデル、トークン数、ポイント数。ポイントの残高と増減。
- 接続したモデルサービス：サービスのアドレスと API キー。キーは暗号化して保存し、そのサービスを呼び出すときにのみ復号します。
- 利用者に送ったメール：宛先と内容。
- サーバーのログ：リクエストごとのメソッド、パス、ホスト、ポート、結果、所要時間、利用者の IP アドレス。エラーの場合はエラーコードとプログラム内の発生箇所。アドレスのクエリ部分（検索語やリンク内のトークンなど）は削除し、Cookie、メッセージやメモの内容はログに記録しません。IP アドレスは、リクエストの回数制限のためにもメモリ上で使用します。
- 利用者のブラウザ：ログイン用の Cookie（スクリプトからは読めません）。返信の下にポイントを表示するかどうかなど、ブラウザ内だけで使う少量の記録もありますが、運営者には送信しません。

広告や分析のサービスは利用していません。

メッセージ、ファイル、メモはサーバー上でエンドツーエンド暗号化されていません。運営者は技術的には保存された内容を見ることができます。{{オーナーが記入：運営者が内容を見るのはどのような場合か（例：通報への対応、障害の調査、法令による要請）}}

## 利用目的

- メッセージを保存して届け、どの端末でも同じ内容が見られるようにするため。
- Agent が返信し、物事を覚え、記憶を整理し、会話の古い部分を要約するため。Agent のオーナーが「主动参与群聊」（自分からグループの会話に参加する）をオンにしている場合は、グループで発言するかどうかを判断するため。
- 利用量とポイントを計算し、不正利用を防ぐため（リクエストの回数制限など）。
- アカウントに関するメール：メールアドレスの確認、パスワードの再設定、利用者のアドレスで登録が試みられたときのお知らせ。
- お問い合わせへの返信と通報への対応のため。

利用者の情報を販売したり、広告に利用したり、アプリをまたいで追跡したりすることはありません。

## 第三者への提供

Agent の返信、記憶、要約、発言するかどうかの判断は AI モデルが行うため、内容を AI モデルの提供者に送る必要があります。

- 本サービスのモデル：運営者がこれらの提供者のアカウントを持っています。返信、記憶の整理、要約、発言の判断、Agent の設定の下書きに使われることがあります。現在の提供者：{{オーナーが記入：本サービスのモデルの提供者名}}。
- Agent のオーナーが接続したモデルサービス：Agent のオーナーが自身のアカウントを接続している場合、その Agent の返信はそのサービスに送られます。オーナーは自身の記憶の整理にそのサービスを選ぶこともできます。そのサービスは Agent のオーナーが選んだものです。

モデルに送る内容には次のものが含まれます。

- Agent の設定とメモ、会話の要約、メンバーの名前、モデルが読める画像とファイル
- 会話の最近のメッセージ。グループでは他のメンバーの発言も含みますが、その Agent がグループに参加した後のものに限ります
- Agent が自ら調べた内容：グループでは、Agent と質問した人の双方が見られるそのグループの履歴全体（Agent の参加以降）を検索し、その中のテキストファイルを読むことができます。オーナーとの専用の会話では、Agent が参加しているすべてのグループを検索できます
- ウェブ検索で見つかった内容

次の提供者も一部の情報を受け取ります。

- ウェブ検索：Agent のウェブ検索がオンの場合、Agent が会話をもとに考えた検索語を検索サービスに送ります（本サービスは Exa または DeepSeek を利用でき、運営者が設定します）。
- メール：本サービスがメールを送る場合は Resend を利用します。Resend は利用者のアドレスとメールの内容を受け取ります。
- サーバーとファイルの保存：{{オーナーが記入：ホスティング事業者、ファイル保存の事業者、データが保存される国・地域}}。

## グループの他のメンバーに見えるもの

- グループのメンバーには、利用者がそのグループで送ったメッセージやファイルが表示されます。
- グループに他の利用者の Agent がいる場合、グループでの発言はその Agent のモデルに返信の生成のために渡され、Agent の記憶に残ることがあります。記憶には誰がどのグループで発言したかが記録され、その Agent のオーナーが見ることができます。
- その Agent のオーナーは、専用の会話で、Agent が参加しているグループの発言（利用者の発言を含みます）を Agent に調べさせることができます。
- その Agent の「群里没找到时悄悄告诉我」（グループで見つからないときにこっそり知らせる）がオン（初期設定）の場合：あるグループで見つからなかったとき、Agent はオーナーと Agent の双方が参加している他の会話を検索します。見つかった内容は、まずオーナーにだけ知らされます。オーナーが「告诉他们」（伝える）を選んだ場合に限り、Agent はそのグループで自分の言葉で伝え、どこで見つけたか、誰の発言かは言いません。そのため、あるグループでの発言が、そのオーナーの同意のもとで別のグループに伝えられることがあります。

## 保存期間

- メッセージ、画像、ファイル：会話の中に保存されます。現在、自動では削除されません。
- アップロードしたまま送信しなかったファイル：1 時間後に削除します。
- 記憶の変更記録：30 日後に削除します。
- ささやき：誰も対応しないものは 7 日で期限切れになります（「別の場所で見つかった」種類は初期設定で 24 時間）。対応済みや期限切れのものは、表示から 30 日後に削除します。
- 会話の要約：新しい話題を始めたとき、または Agent がグループを退出したときに削除します。
- ログイン：7 日間使わないと自動的にログアウトし、使うと延長されます。メールアドレス確認のリンクは 24 時間、パスワード再設定のリンクは 1 時間有効です。ログインの記録は、現在、定期的には削除していません。
- アカウント、Agent、記憶、利用量、実行記録、メールの記録：現在は保存したままです。

## 削除できるもの

現在、次のことができます。

- Agent の記憶メモと、Agent が聞いた発言を 1 件ずつ削除する
- Agent を削除する：Agent は返信しなくなり、すべてのグループから退出します。グループでの発言は残ります。各人の呼び方、会話の要約、オーナーの判断を待つ記憶の変更は削除されます。名前、アイコン、設定、記憶メモ、聞いた発言、オーナーとの会話、実行記録は、現在は保存されたままです（記憶は Agent を削除する前に 1 件ずつ削除できます）
- 接続したモデルサービスとそのキーを削除する
- アイコンを変更する
- グループからの退出、友だちの削除、相手のブロック

送信したメッセージは、現在は削除できません。

## AI に発言を読ませないようにするには

現在、専用の設定はありません。Agent との会話をやめ、Agent がいるグループから退出することはできます。

## セキュリティ

- ログイン用の Cookie はスクリプトから読めません。
