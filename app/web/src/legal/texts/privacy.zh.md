## 我们保存什么

- 账号：邮箱、昵称、账号名、头像和密码。密码只保存散列，我们看不到原文。
- 你放弃的账号名：改了账号名以后，旧的名字一直留给你，别人不能再用。
- 注册用的邀请码：哪个邀请码让你注册的。
- 每次登录：登录的时间、什么时候到期，以及你的浏览器或设备的说明（浏览器发来的 User-Agent，例如浏览器的名称和版本；在 Haiyo 的 iOS 应用里还有应用的版本）。登录记录里不存 IP 地址。
- 你的确认：你同意了哪一版服务条款和隐私政策、什么时候同意的，以及你确认已满 18 岁的时间。我们不问、也不保存你的出生日期。
- 你发的内容：私聊和群聊里的消息、你发的图片和文件，以及你在每个对话里读到了哪里。
- 你的 Agent：名字、头像、你写的设定和其他设置、它对各人的称呼；它的回复（模型写出思考过程时，思考过程也和回复一起保存，在群里只给 Agent 的主人看）；它提出的设定修改建议；每次回复的运行记录（状态、时间、出错原因）。
- Agent 的记忆（只在它开着记忆时）：关于你的笔记、它自己学到的事，以及它在群里听到的别人的话，连同说话人的名字和群名。
- 对话摘要：对话长了以后，Agent 用模型把较早的内容写成一份摘要，按对话和 Agent 各存一份。
- 悄悄话：Agent 只给它的主人看的提示。还有记忆的修改记录。
- 社交关系：好友、好友申请、拉黑，以及你在哪些群里。
- 用量：每次调用 AI 模型时用了哪个模型、多少 token、多少点数，以及你的点数余额和变动。
- 你接入的模型服务：服务地址和 API 密钥。密钥加密保存，只在调用那家服务时解开。
- 发给你的邮件：收件地址和邮件内容。
- 服务器日志：每个请求的方法、路径、主机、端口、结果和用时，以及你的 IP 地址；出错时还有错误代码和程序的出错位置。网址里的查询部分（比如搜索词、链接里的令牌）会被抹掉，cookie 不写进日志，消息和笔记的内容也不写进日志。你的 IP 地址还在内存里用来限制请求的频率。
- 你的浏览器里：登录用的 cookie（脚本读不到）；还有少量只在你的浏览器里用的记录，比如要不要在回复下显示点数，不发给我们。

我们没有接入任何广告或统计服务。

消息、文件和笔记在服务器上不是端到端加密的：运营者在技术上能看到保存的内容。{{待主人填：运营者在什么情况下查看（例如处理举报、排查故障、法律要求）}}

## 我们用这些信息做什么

- 保存和送达消息，让你在不同设备上看到同样的内容。
- 让 Agent 回复、记住事情、整理记忆、给较早的内容写摘要；Agent 的主人打开“主动参与群聊”时，判断它要不要在群里开口。
- 计算用量和点数，防止滥用（比如限制请求的频率）。
- 发账号邮件：验证邮箱、重置密码，以及有人想用你的邮箱注册时提醒你。
- 回复你的来信、处理举报。

我们不卖你的信息，不用它做广告，也不做跨应用追踪。

- Agent 主人自己接入的模型服务：一个 Agent 的主人填了自己的服务账号时，这个 Agent 的回复会发到那里；主人也可以选它来整理自己的记忆。那家服务由 Agent 的主人选择。

发给模型的内容包括：

- Agent 的设定和笔记、对话摘要、成员的名字，以及模型能读的图片和文件；
- 对话里最近的消息。在群里也包括其他成员的发言，只限这个 Agent 进群以后的消息；
- Agent 自己查到的内容：在群里，它可以搜索这个群里它和提问的人都能看到的全部历史（从它进群以后），并读出其中的文字文件；在它和主人的专属对话里，它可以搜索它所在的每一个群；

## 群里别人能看到什么

- 群里的成员能看到你在群里发的消息和文件。
- 群里有别人的 Agent 时，你在群里的发言会交给那个 Agent 的模型来生成回复，也可能被它记进记忆：记忆里写着是你说的、在哪个群说的，那个 Agent 的主人能看到。
- 那个 Agent 的主人可以在专属对话里让它查找它所在的群里说过的话，包括你在群里的发言。
- 那个 Agent 开着“群里没找到时悄悄告诉我”（默认开着）时：它在一个群里没查到，会去它和主人都在的其他对话里查。查到了只先悄悄告诉主人；主人选“告诉他们”，它才在这个群里用自己的话转述，不说在哪里看到、是谁说的。所以你在一个群里说的话，可能经那位主人同意，被转述到另一个群。

## 保存多久

- 消息、图片和文件：一直保存在对话里，现在没有自动删除。
- 上传了但没有发出去的文件：1 小时后删除。
- 记忆的修改记录：30 天后删除。
- 悄悄话：没人处理的，7 天后过期（“在别处查到”的那种默认 24 小时）；处理过或过期的，在出现 30 天后删除。
- 对话摘要：开始新话题或 Agent 退出群时删除。
- 登录：7 天不用就会自动退出，用的时候会延长。验证邮箱的链接 24 小时有效，重置密码的链接 1 小时有效。登录记录现在没有定期清除。
- 账号、Agent、记忆、用量、运行记录和邮件记录：现在一直保存。
- 服务器日志：{{待主人填：托管商保存日志多久}}。

## 你可以删除什么

现在你可以：

- 删除 Agent 的记忆笔记和它听到的话，一条一条地删；
- 删除你的 Agent：它不再回复，退出所有群，它在群里说过的话会留下。它对各人的称呼、对话摘要和等你决定的记忆修改会删除；它的名字、头像、设定、记忆笔记、听到的话、和你的对话、运行记录现在仍然保存（记忆可以在删除 Agent 之前先逐条删掉）；
- 删除你接入的模型服务和它的密钥；
- 换掉头像；
- 退出群聊、删除好友、拉黑别人。

现在还不能删除已经发出的消息。
